🏥 RAJ Dispensary System

A full-stack Drug Dispensary Management System built with FastAPI, MongoDB, and JavaScript (HTML/CSS) — enabling doctors to create prescriptions and pharmacists to dispense drugs securely.

🚀 Features

👨‍⚕️ Doctor: Create & manage prescriptions

💊 Pharmacist: View & dispense prescriptions

🔐 JWT-based authentication

💾 MongoDB for data storage

🌐 RESTful API with FastAPI

🎨 Responsive frontend (HTML, CSS, JS)

🧱 Tech Stack

Backend: FastAPI, MongoDB, Motor, Passlib, Python-Jose
Frontend: HTML, CSS, JavaScript (Fetch API)
Server: Uvicorn
